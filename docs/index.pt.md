# Soulglass

Complemento de morte para **Minecraft Bedrock 1.26**. Quando morres, os teus itens e a tua experiência ficam guardados numa lanterna das almas, acesa no sítio onde caíste. Um guia leva-te de volta, e partir a lanterna devolve tudo — armadura incluída.

Só o dono abre a lanterna, e nada mais no jogo a consegue destruir.
