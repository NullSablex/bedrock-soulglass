# Soulglass

适用于 **Minecraft 基岩版 1.26** 的死亡附加包。你死亡时，物品和经验会留在一盏灵魂灯笼里，点亮在你倒下的地方。向导带你回去，打破灯笼即可取回全部——盔甲也在内。

只有主人能打开灯笼，游戏中没有任何东西能摧毁它。
